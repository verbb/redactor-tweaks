Redactor Tweaks makes small, deliberate adjustments to the Redactor editing interface for projects that still use Craft’s Redactor plugin. Reduce visual bulk and give long editing sessions a more compact workspace.

Use a smaller default font, text size, and toolbar controls so the field consumes less space in the control panel. The changes target the authoring interface rather than rewriting the HTML stored by Redactor.

## Features

- **Compact text:** Reduce the editor’s default type size for a denser workspace.
- **Neutral font:** Use a familiar interface font in place of Redactor’s default.
- **Smaller toolbar:** Reduce button size so formatting controls take up less room.
- **Authoring-only changes:** Adjust the control-panel editor without changing saved content.
- **Redactor integration:** Apply to fields provided by Craft’s Redactor plugin.
- **Project-wide behaviour:** Keep the interface treatment consistent across eligible fields.
- **Consistent Redactor styling:** Enable the tweaks at the project level instead of maintaining a custom stylesheet for every Redactor field or control-panel bundle.
