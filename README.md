<h1 align="center">Redactor Tweaks for Craft CMS</h1>

Redactor Tweaks is a Craft CMS plugin that makes small, deliberate adjustments to the Redactor editing interface for projects that still use Craft's Redactor plugin. Reduce visual bulk and give long editing sessions a more compact workspace.

Use a smaller default font, text size, and toolbar controls so the field consumes less space in the control panel. The changes target the authoring interface rather than rewriting the HTML stored by Redactor.

## Features

- Reduce the editor's default type size for a denser workspace.
- Use a familiar interface font in place of Redactor's default.
- Reduce button size so formatting controls take up less room.
- Adjust the control-panel editor without changing saved content.
- Apply to fields provided by Craft's Redactor plugin.
- Keep the interface treatment consistent across eligible fields.
